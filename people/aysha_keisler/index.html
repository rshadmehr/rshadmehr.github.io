Aysha Keisler

Postdoctoral fellow (2008-2011)

Biomedical Engineering
Johns Hopkins University

Research

Aysha joined the lab in 2008 as a postdoc after completing her PhD in Psychology from University of Virginia. Aysha made the important discovery that the fast component of the motor memory was very likely neurally distinct from the slow component. She made this inference by inventing a task in which she could selectively disrupt the fast process via a task the engaged the declarative memory system. She was awarded an NRSA postdoctoral grant. She subsequently took a position as Research Scientist, Ipsos Public Affairs.

Ideas developed by Aysha

  • Discovering shared resources between declarative memory and motor memory. Aysha showed that engaging declarative memory immediately after motor learning selectively interferes with the fast component of motor adaptation. In contrast, the slow component remains unaffected. This provided evidence that the fast process of motor learning shares resources with declarative memory, challenging the traditional distinction between cognitive and motor memory systems.
  • Providing evidence that fast and slow motor memories rely on distinct neural processes. By demonstrating that a declarative memory task disrupts fast motor memory but not slow motor memory, Aysha provided evidence that the two adaptive processes are functionally distinct and may depend on different neural systems.
  • Revealing competition between memory systems during consolidation. Aysha discovered that disrupting the fast component of motor memory immediately after learning can improve its retention several hours later. This surprising result suggested that declarative and nondeclarative memory processes compete during consolidation, so weakening one component can strengthen the eventual expression of another.
